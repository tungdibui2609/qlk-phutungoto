🌐 Hướng Dẫn Thêm Tên Miền Mới Vào Hệ Thống

Chỉ mất 2 phút để liên kết tên miền riêng của bạn với chiếc laptop này thông qua Cloudflare Tunnel!

⚡ Công cụ tạo cấu hình DNS nhanh

Nhập tên miền bạn muốn thêm vào ô bên dưới, bảng hướng dẫn sẽ tự động cập nhật chính xác các giá trị cần điền:

1
Thao tác trên trang quản trị Cloudflare Dashboard

Đăng nhập vào tài khoản dash.cloudflare.com của bạn, chọn tên miền khohangmoi.com → Vào mục DNS → Records → Nhấn Add record và thêm 3 bản ghi CNAME sau:

Loại (Type) Tên (Name) Giá Trị Trỏ Đến (Target) Đám Mây (Proxy) Mục Đích
CNAME @ 9df90c7f-63cf-4ac9-87f1-f615c0292e4d.cfargotunnel.com 🟠 Proxied Trang chủ Web App
CNAME www 9df90c7f-63cf-4ac9-87f1-f615c0292e4d.cfargotunnel.com 🟠 Proxied Hỗ trợ tiền tố www
CNAME api 9df90c7f-63cf-4ac9-87f1-f615c0292e4d.cfargotunnel.com 🟠 Proxied Kết nối CSDL Supabase
⚠️
LƯU Ý QUAN TRỌNG: Mục Proxy status bắt buộc phải chọn Proxied (Đám mây màu cam 🟠) thì Cloudflare mới tạo chứng chỉ bảo mật SSL HTTPS và bảo vệ IP laptop của bạn!
2
Thao tác 1-Click trên Laptop (Trong phần mềm Server Launcher)

Trên laptop, bạn không cần phải sửa file cấu hình thủ công nữa. Hãy làm như sau:

  1. Mở bảng điều khiển Modular WMS - Server Controller.
  2. Bấm vào nút "🌐 QUẢN LÝ TÊN MIỀN".
  3. Nhập tên miền của bạn (ví dụ: khohangmoi.com) vào ô và bấm "Thêm Tên Miền Ngay".
  4. Hệ thống sẽ tự động ghi cấu hình và tự khởi động lại Cloudflare Tunnel chỉ sau 2 giây!
🎉
TỰ ĐỘNG 100%: Mã nguồn của hệ thống đã được tích hợp cơ chế Smart Multi-Domain. Khi nhân viên truy cập vào https://khohangmoi.com, Web App sẽ tự động bắt tay với API cục bộ qua Tunnel mà bạn không cần phải cấu hình thêm bất kỳ thứ gì!
3
Chế độ Chạy Localhost Offline (Khi không có mạng)

Hệ thống được thiết kế để hoạt động hoàn hảo trong 2 trường hợp:

💻 Bạn (Trên chiếc Laptop này):

Mở http://localhost:3000. Chạy trực tiếp qua mạng nội bộ máy tính. Tốc độ cực nhanh < 1 mili-giây. Rút dây mạng, tắt WiFi vẫn chạy 100%!

📱 Nhân viên (Quét mã từ xa):

Mở tên miền https://khohangmoi.com hoặc https://chanhthu.click. Đi qua Cloudflare Tunnel để kết nối vào máy chủ laptop này.
